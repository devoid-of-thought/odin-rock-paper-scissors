# Rock, Paper and Scissors

Project created for [Project Odin](https://www.theodinproject.com/lessons/foundations-rock-paper-scissors)


## Features 

Simple website with three buttons.

![website](./images/base.png)

When either player or computer wins the buttons become blocked.

![alt text](/images/computer_win.png)

The game resets upon website refresh.
